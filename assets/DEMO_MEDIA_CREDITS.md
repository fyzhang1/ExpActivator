# ExpActivator demo production notes

The 12-second film illustrates personalized coffee ordering and a context-aware morning weather suggestion. It plays the 24-second edit at 2× speed, with pitch-preserving audio acceleration.

This is a scripted illustrative simulation, not a recording of live model inference. Application screens, histories, preferences, prices, clock values, forecasts, and outcomes are example data. No real purchase or payment is performed. The simulated user confirms the example order and accepts the weather suggestion.

All screen artwork and animation were created for the film using Canvas. No third-party stock footage is used. The score and interface sounds are original procedural synthesis; voices use local macOS speech synthesis.

Video: 1920 × 1080, 30 fps, H.264, with stereo AAC audio.
